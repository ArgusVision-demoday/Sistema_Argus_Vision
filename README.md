# Argus Vision

Site institucional do **Argus Vision**, um sistema de tecnologia assistiva voltado para tutores de cães-guia, oferecendo mais autonomia e segurança durante os passeios.

## Páginas

| Página | Descrição |
|--------|-----------|
| `index.html` | Home — apresentação do produto |
| `pages/Sobre.html` | Sobre o time |
| `pages/Produto.html` | Detalhes do produto |
| `pages/Cadastro.html` | Cadastro de usuário |
| `pages/Login.html` | Login |
| `pages/Pagamento.html` | Checkout |
| `pages/Suporte.html` | Suporte |

## Como rodar localmente

Basta abrir o `index.html` em qualquer navegador moderno — não há dependências de build.

Para um servidor local rápido (recomendado para evitar restrições de CORS):

```bash
# Python 3
python -m http.server 8080
```

Acesse `http://localhost:8080`.
